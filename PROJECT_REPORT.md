# Project Report
## Apartment Maintenance and Resident Complaint Management System

### Abstract
This project manages apartment details, residents, monthly maintenance bills, payment status and resident complaints. Java handles operations, PostgreSQL stores data, JDBC connects the application to the database, and Python/Pandas analyses exported reports and creates charts.

### Problem statement
Paper-based or scattered records make resident information, payment follow-up and complaint tracking difficult to maintain.

### Objectives
1. Maintain resident and apartment records.
2. Record monthly maintenance bills and payment status.
3. Register complaints and track OPEN, IN_PROGRESS and RESOLVED status.
4. Generate payment and complaint reports.
5. Analyse report data and visualize status counts.

### Modules
Resident Management; Apartment Management; Maintenance Billing; Payment Tracking; Complaint Management; Reporting and Visualization.

### Technology
Java 17, PostgreSQL, JDBC, Maven, Python, Pandas, Matplotlib, VS Code and pgAdmin 4.

### Conclusion
The system centralizes apartment operations and provides database-backed reports with basic data visualizations.

### Future enhancement
Add a GUI, login/roles, notifications and PDF report generation.
